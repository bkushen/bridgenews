# What's On sources

BridgeNews aggregates live entertainment listings from public cinema, organiser and ticketing pages. It does not fill gaps with news articles or invented events.

## Display rules
- Visual What’s On modules only show listings with a real poster/event image.
- Duplicate movie titles from several cinema chains are merged into one card.
- Provider/ticket links from all matching sources are kept on the merged item.
- Richer metadata wins when sources disagree or one source provides more fields.
- Listings are region-scoped and refreshed from source pages every 15 minutes.
